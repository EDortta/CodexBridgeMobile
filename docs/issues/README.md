# Issue Tracking

Issues for Codex Bridge Mobile are organized by phase and solved one at a time.

Each issue records context, objective, scope, ARO criteria, test plan, and
definition of done before implementation starts. A behavior change receives its
own focused tests, critical review, and commit.

## Statuses

- `[draft]` — being specified; no implementation branch.
- `[ready]` — approved for branch authorization.
- `[started]` — implementation in progress on an authorized branch.
- `[review]` — checks completed and ready for review.
- `[finished]` — accepted and complete.
- `[blocked]` — cannot progress without an explicit external decision or input.
